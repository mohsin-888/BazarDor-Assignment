 BazarDor

BazarDor is a daily essential prices of daily essential products in Bangladesh.

Features;

-View latest prices of daily essential products
-See products whose prices increased or decreased
-Browse products by category
-Sort products from low to high or high to low price
-View detailed market-wise product prices
-Email and password authentication
-Google and GitHub social login
-Protected product details page
-User profile and name update
-Responsive design for mobile, tablet and desktop
-Loading skeletons and custom 404 page

Technologies;


-Next.js
-TypeScript
-Tailwind CSS
-Better Auth
-PostgreSQL / Neon
-React Hot Toast
Authentication;

Authentication is implemented using Better Auth with:

-Email & Password
-Google
-GitHub

API;

Product data is loaded from the BazarDor API.
